# FluentDocs

Fluent document generation for .NET — DOCX, PDF, XLSX, PPTX, Markdown, CSV and charts from one API. This umbrella package pulls in every renderer and registers them with AddFluentDocs().

Part of [FluentDocs](https://github.com/deniscuciuc/fluentdocs). See the [documentation](https://github.com/deniscuciuc/fluentdocs#readme) for usage.

```
dotnet add package FluentDocs
```
