# FluentDocs.Presentations

PPTX presentation generation for FluentDocs, built on DocumentFormat.OpenXml.

Part of [FluentDocs](https://github.com/deniscuciuc/fluentdocs). See the [documentation](https://github.com/deniscuciuc/fluentdocs#readme) for usage.

```
dotnet add package FluentDocs.Presentations
```
