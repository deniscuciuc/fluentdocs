# FluentDocs.Charts

Chart rendering for FluentDocs, backed by ScottPlot. Produces PNG and SVG for embedding in documents, spreadsheets and presentations.

Part of [FluentDocs](https://github.com/deniscuciuc/fluentdocs). See the [documentation](https://github.com/deniscuciuc/fluentdocs#readme) for usage.

```
dotnet add package FluentDocs.Charts
```
